# Публичные данные и приватность

В этой поставке есть код, критерии, каталоги механизмов ошибок, синтетические примеры и агрегаты двух исторических запусков.

Не включены фотографии учеников, буквальные транскрипции реальных работ, индивидуальные оценки, исходные ответы провайдеров, финансовый журнал, действующие разрешения, контактные данные, ключи и приватная Git-история. Даже демонстрационные рукописные страницы из прежнего приватного репозитория не переносились.

В тестах встречаются искусственные ключи и вымышленные финансовые события. Они проверяют, например, что ключ не попадает в диагностический текст. Они не дают доступа к провайдерам.

Математические формулировки задач, самостоятельные ключи и краткие пересказы опубликованных пограничных случаев входят в методические зависимости кода. Источник и статус интерпретации указаны отдельно; рукописные сканы этих случаев не публикуются.

Публичный репозиторий создаётся из отобранного списка файлов в отдельной папке. `RELEASE.json` фиксирует хеши исходников. Публичные пути к ключам заменены на заведомо несуществующий путь. Оперативная policy не экспортируется.

Локальное приложение хранит добавленные пользователем материалы в `data_local/`. Эта папка исключена из Git. Исключение из Git не заменяет согласие на передачу данных: реальная проверка требует отдельного решения владельца данных и настройки допуска.
