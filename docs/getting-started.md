# Запуск без платных запросов

Проверенная среда — **macOS и Python 3.14**; она же выбрана для автоматического запуска на GitHub. Приложение использует POSIX-блокировки, поэтому Windows напрямую не поддерживается.

При первом полном запуске на Linux отдельный исполнитель точных операций остановился по своему порогу памяти ещё на подготовке. Порог не увеличивался и проверки не отключались; полный набор на Linux пока не подтверждён. Эти восемь операций отделены от основного модельного маршрута. Исторический запуск сохранён в GitHub Actions.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/setup_runtime.py
python scripts/check.py
python scripts/demo.py
```

`setup_runtime.py` устанавливает SymPy в отдельное окружение `data_local/live_runtime`. Для установки зависимостей нужен доступ к индексу пакетов. Демонстрация и тесты не отправляют обращения моделям.

## Локальное приложение

```sh
python -m app.server --port 8766
```

Открыть <http://127.0.0.1:8766>. Интерфейс позволяет сохранить условие и искусственные изображения локально. Реальные платные проверки недоступны: в поставке нет активной policy, ключей или бюджета. Файлы с `public_placeholder` — намеренно недействующие маркеры для сохранения карты конфигурации, они не являются финансовыми разрешениями.

Не нужно вводить API-ключ для знакомства с проектом. Публичная версия не является готовым общедоступным сервером проверки. Сайт [kexam.ru](https://kexam.ru) имеет отдельное развёртывание.

## Что проверяет набор тестов

`scripts/check.py` запускает регрессии приложения, контракта M01 и точных операций. Используются искусственные изображения, ответы, ключи и временные журналы. Отдельные тесты могут создавать локальный HTTP-сервер; внешние соединения запрещены.

В публичном запуске исторические разрешения расходов заменяются искусственными контрольными объектами только на время тестов. Тесты, которым нужны настоящие приватные фото или точные подписанные разрешения, явно показываются как `skipped`. Они не входят в число прошедших. Производственный код ради этого не изменён. Прямой запуск всех исторических тестов через `unittest discover` без этой обвязки требует внутренней среды.

Эти проверки устанавливают техническое поведение: схему, привязки, сохранение, допуск, отказ повторов, работу математических операций. Они не измеряют качество OCR и оценивания моделей.

## Пересчитать рисунок бенчмарка

```sh
python -m pip install -r requirements-figures.txt
python scripts/render_figures.py
python scripts/verify_release.py
```

Числа берутся только из `benchmarks/school-82.json`. Для повторения исходных модельных запусков публичных агрегатов недостаточно: фото и индивидуальные результаты не распространяются.
