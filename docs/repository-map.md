# Карта репозитория

| Путь | Содержание |
|---|---|
| `app/` | Локальный сервер, чтение, оценка, хранение, расходы и продолжение |
| `app/independent_prompts/` | Раздельные инструкции самостоятельному решателю и оценщику №13/№15 |
| `app/m05/` | Замороженный пакет прежних структурированных промптов; остаётся зависимостью чтения и диагностик |
| `app/tests/` | Технические регрессии, преимущественно на искусственных данных |
| `contracts/ege_v1/` | M01: схема подробного результата, валидатор, искусственные примеры и тесты |
| `exact_checks/` | Отдельные точные операции и защищённый исполнитель |
| `planning/m02/`, `planning/m03/` | Предметные критерии и правила №13/№15, зависимости кода |
| `planning/error_types_2026-10-10/` | Каталог 97 типов и инструкция его применения |
| `planning/k01/`, `planning/k05/` | Протокол точных операций и методические механизмы |
| `planning/m05/` | Отпечатки замороженного пакета, математические ключи и синтетические примеры |
| `planning/l04/` | Исторические профили запросов для совместимости офлайн-тестов; не текущая конфигурация продукта |
| `planning/l05/`, `planning/m17/` | Недействующие публичные маркеры и обезличенные примеры настроек; активного допуска нет |
| `benchmarks/` | Только сводные числа и происхождение опубликованных результатов |
| `docs/` | Архитектура, методика, решения, результаты и приватность |
| `scripts/` | Бесплатная демонстрация, тестовая обвязка, рисунки и проверка поставки |

Названия `m02`, `m05`, `k01` остались в путях, потому что на них ссылается код. Внутренний план задач и переписка в публичную поставку не входят.

В исходных комментариях могут встречаться внутренние коды работ и исторические версии моделей. Это контекст разработки, а не включённые наборы ученических данных. Рабочий маршрут описан в [architecture.md](architecture.md); старые профили не нужно воспринимать как рекомендуемые настройки новых запусков.
