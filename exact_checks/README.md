# Точные математические операции

Восемь операций: принадлежность корня промежутку, отбор из серий, равенство точек окружности, объединение, пересечение, принадлежность и равенство множеств, проверка ненулевого знаменателя.

Чистая математика находится в `trig.py` и `sets.py`, протокол — в `protocol.py`, интеграция с офлайн-конвейером — в `operations.py`. Схема запроса и реестр — в [planning/k01/](../planning/k01/).

Набор не подключён целиком к основному модельному пути. Каждая операция требует известного контекста и источников аргументов; неопределённость чтения не устраняется вычислением. [Область применения](../docs/architecture.md#точные-проверки)

Ограниченный исполнитель использует отдельный процесс, таймауты и наблюдение за RSS. Наблюдение за памятью не является жёстким лимитом выделения памяти ОС. Тесты входят в `python scripts/check.py`.
