# Ядро EGEChecker

Вход в документацию: [главная страница](../README.md), [архитектура](../docs/architecture.md), [локальный запуск](../docs/getting-started.md).

Новые проверки исполняет `independent_checking.py`; общие сохранение, очередь и допуск остаются в `live_checking.py`. Подробный офлайн-конвейер `pipeline.py` сохранён отдельно и не является текущим исполнителем модели.

Публичная конфигурация намеренно не разрешает платных обращений. Прежние внутренние инструкции эксплуатации сюда не переносились.
