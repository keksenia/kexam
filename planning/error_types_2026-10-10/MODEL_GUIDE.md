# Как используется каталог

`catalog.json` хранит предметные определения, условия подтверждения, исключения и контрасты. `app/independent_assessment.py` собирает запрос оценки с предметным каталогом и критериями для выбранного задания. [Точка входа](../../app/independent_assessment.py)

Тип ошибки объясняет механизм; он не назначает балл. Оценщик должен проверить конкретный переход, остальные существенные шаги и применимость критерия. Неподтверждённый механизм нельзя выдавать за установленный только ради заполнения категории.

Текущий формат допускает также `typo`, `unclassified` и `system_uncertainty`. Замечание связано с существующей строкой; для отсутствующего шага или адресного вопроса возможна пустая ссылка. [Формат результата](../../docs/architecture.md#оценщик-и-результат)
